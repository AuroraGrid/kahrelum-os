Election data directory

Read KAHRELUM's published election observations, coalition records, and competition-method snapshots in their original context. This directory is a human-readable entry point. The linked JSON files remain independent source records, with their own cutoffs, fields, corrections, and verification status.

Evidence boundary. A source observation is not a certified election result. Historical locks are not rewritten after outcomes become available. An unfinished comparison or unresolved official result must remain explicitly unresolved; this directory does not change any earlier forecast, score, or source record.
